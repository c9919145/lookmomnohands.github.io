# AliExpress US Replica

A demonstration/educational clone of the AliExpress US homepage built with **Vue 3 + Vite + Tailwind CSS + Pinia**.

**Live site:** https://lookmomnohands.github.io/

## Features
- Full homepage with hero carousel, Welcome Deal, SuperDeals countdown, product shelves
- Category listing pages with sidebar + sorting
- Product detail pages with add-to-cart
- Search
- Cart with localStorage persistence

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
Output goes to `dist/`. Deployed automatically to GitHub Pages via `.github/workflows/deploy.yml`.

> This is a UI demo using placeholder images (placehold.co) and sample data. Not affiliated with AliExpress.
